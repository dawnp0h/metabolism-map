# Integrated Metabolism Map

An interactive STEP 1 biochemistry map: glycolysis, TCA, urea cycle, amino acids, organic acidemias, heme, lysosomal storage diseases and more, with numbered disease badges and key-findings boxes.

## Features
- **Zoom:** − / Fit / + buttons, scroll to zoom, drag to pan
- **Cofactors:** click a vitamin (B1–B12) to highlight every step that uses it
- **Disease list:** click a disease to locate and highlight its enzyme step on the map
- **Clear highlight** resets the view

## Live site
https://dawnp0h.github.io/metabolism-map/

The whole map is a single self-contained `index.html` (no build step, no dependencies besides the Inter web font).
